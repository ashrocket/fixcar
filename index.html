Why This Is Better

The old app never loaded your source model. It embedded somebody else's car viewer and layered a 2D diagram on top. This version works from your STL and lets you physically pull out the front-corner slice as its own movable guide.

What Still Blocks Accuracy

The STL is a printable whole-body shell with supports baked in. It does not contain a true fender part, hole geometry, bracket faces, or fastener hardware. The install markers are guidance points, not exact mesh-derived holes.

Best Upgrade Path

If you can get a clean front-right fender CAD, STEP, OBJ, or a support-free STL, this viewer can swap from region extraction to a true part overlay with much better fit-up and fastener alignment.

Asset Reality Check

Your archive contains a single Blender-exported binary STL of a small printable Camaro body with print supports. It is not a repair assembly model. That is why the previous app drifted into theater instead of useful installation tooling.
